# HIS-Mixed MVP演示说明

## 一、演示环境准备

### 1.1 启动基础设施
```bash
# 启动数据库和中间件
cd docker
docker-compose up -d postgres redis rabbitmq nacos minio
```

### 1.2 初始化数据库
```bash
# 执行数据库迁移
cd backend/go
./scripts/db_init.sh

# 插入演示数据
psql -U his -d his_auth -f sql/seed_data.sql
psql -U his -d his_registration -f sql/demo_data.sql
```

### 1.3 启动后端服务
```bash
# 启动Go服务
cd backend/go
go run cmd/gateway/main.go &
go run cmd/registration/main.go &
go run cmd/schedule/main.go &
go run cmd/pharmacy/main.go &

# 启动Java服务
cd backend/java
mvn spring-boot:run -pl his-auth &
```

### 1.4 启动前端应用
```bash
# 患者端 (端口5174)
cd frontend/his-web-patient
npm run dev

# 管理端 (端口5175)
cd frontend/his-web-admin
npm run dev
```

## 三、演示流程

### 3.1 管理端演示（http://localhost:5175）

#### 步骤1：管理员登录
1. 访问 http://localhost:5175
2. 输入账号 `admin` / `admin123`
3. 点击登录

#### 步骤2：查看工作台
- 查看今日统计数据（挂号数、就诊数、处方数、收入）
- 查看最近挂号记录
- 使用快捷操作按钮

#### 步骤3：医生管理
1. 点击左侧菜单"业务管理" → "医生管理"
2. 查看医生列表（5位医生）
3. 演示功能：
   - 搜索：按姓名/科室筛选
   - 新增：点击"新增医生"按钮
   - 编辑：点击"编辑"修改医生信息
   - 状态切换：启用/停用医生

#### 步骤4：排班管理
1. 点击左侧菜单"排班管理"
2. 查看排班列表
3. 演示功能：
   - 查看排班：按医生、科室、日期筛选
   - 新增排班：点击"新增排班"
   - 批量排班：点击"批量排班"，设置日期范围和时段

#### 步骤5：药品管理
1. 点击左侧菜单"药品管理"
2. 查看药品列表（10种药品）
3. 演示功能：
   - 搜索：按药品名称/编码筛选
   - 新增：点击"新增药品"
   - 库存调整：点击"库存"进行入库/出库操作
   - 查看库存预警（库存低于最低库存时显示警告）

#### 步骤6：患者管理
1. 点击左侧菜单"患者管理"
2. 查看患者列表
3. 点击"详情"查看患者完整信息

#### 步骤7：系统管理
1. 科室管理：查看科室树形结构
2. 用户管理：查看系统用户列表

---

### 3.2 患者端演示（http://localhost:5174）

#### 步骤1：患者登录
1. 访问 http://localhost:5174

- 查看历史处方记录
- 查看处方详情（药品、用法用量）

## 五、演示要点

### 5.1 功能完整性
- 管理端：医生管理、排班管理、药品管理、患者管理、系统管理
- 患者端：登录、查看医生、在线挂号、查看处方

### 5.2 技术架构
- 前端：Vue3 + TypeScript + Ant Design Vue
- 后端：Go微服务 + Java微服务（混合架构）
- 数据库：PostgreSQL
- 缓存：Redis
- 消息队列：RabbitMQ

### 5.3 系统特点
- 微服务架构，服务独立部署
- gRPC服务间通信
- 统一的API网关
- 完善的权限管理

## 六、常见问题

### Q1: 登录失败
**A**: 检查后端服务是否启动，特别是his-auth服务

### Q2: 数据为空
**A**: 检查是否执行了演示数据脚本

### Q3: 页面无法访问
**A**: 检查前端服务是否启动，端口是否正确（患者端5174，管理端5175）

### Q4: API请求失败
**A**: 检查网关服务是否启动，端口8080是否正常

## 七、演示脚本（快速启动）

```bash
#!/bin/bash
# 一键启动演示环境

# 1. 启动基础设施
cd docker && docker-compose up -d

# 2. 等待数据库就绪
sleep 5

# 3. 初始化数据库
cd ../backend/go
./scripts/db_init.sh

# 4. 启动后端服务
go run cmd/gateway/main.go &
go run cmd/registration/main.go &
go run cmd/schedule/main.go &
go run cmd/pharmacy/main.go &

# 5. 启动前端
cd ../../frontend/his-web-patient && npm run dev &
cd ../his-web-admin && npm run dev &

echo "演示环境启动完成！"
echo "患者端: http://localhost:5174"
echo "管理端: http://localhost:5175"
```
