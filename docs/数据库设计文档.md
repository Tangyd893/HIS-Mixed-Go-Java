## 一、数据库总体设计

### 1.1 数据库选型

| 属性 | 说明 |
| ---- | ---- |
| 数据库 | PostgreSQL 17 |
| ORM (Go) | GORM 2.x |
| ORM (Java) | MyBatis-Plus 3.5+ |
| 驱动 (Go) | pgx 5.x |
| 驱动 (Java) | PostgreSQL JDBC Driver |
| 连接池 (Java) | HikariCP 5.x |

### 1.2 分库策略

采用 **Database per Service** 模式，每个微服务独占一个 PostgreSQL 数据库，共 17 个独立数据库。

| 序号 | 数据库名 | 所属服务 | 语言 | 说明 |
| ---- | -------- | -------- | ---- | ---- |
| 1 | `his_auth` | his-auth | Java | 认证授权、角色权限 |
| 2 | `his_user` | his-user | Java | 患者档案、员工、科室 |
| 3 | `his_registration` | his-registration | Go | 挂号预约、排队叫号 |
| 4 | `his_clinic` | his-clinic | Java | 门诊诊疗、诊断 |
| 5 | `his_emr` | his-emr | Java | 电子病历、CDSS |
| 6 | `his_prescription` | his-prescription | Java | 处方管理 |
| 7 | `his_billing` | his-billing | Java | 收费结算 |
| 8 | `his_pharmacy` | his-pharmacy | Go | 药房库存、发药 |
| 9 | `his_examination` | his-examination | Go | 检查检验 |
| 10 | `his_inpatient` | his-inpatient | Java | 住院管理 |
| 11 | `his_schedule` | his-schedule | Go | 排班号源 |
| 12 | `his_outpatient` | his-outpatient | Go | 院外问诊、慢病 |
| 13 | `his_followup` | his-followup | Go | 随访管理 |

### 1.3 数据库通用约定

#### 命名规范

| 对象 | 规范 | 示例 |
| ---- | ---- | ---- |
| 表名 | 小写蛇形命名，复数形式 | `patients`, `appointments` |
| 主键 | `id`，BIGINT 或 VARCHAR(32) | `id` |
| 外键 | `{关联表单数}_id` | `patient_id`, `department_id` |
| 索引 | `idx_{表名}_{字段名}` | `idx_patients_phone` |
| 唯一约束 | `uk_{表名}_{字段名}` | `uk_patients_id_card` |
| 创建时间 | `created_at` | TIMESTAMP |
| 更新时间 | `updated_at` | TIMESTAMP |
| 删除标记 | `deleted_at` | TIMESTAMP (NULL = 未删除) |

#### 通用列

每个业务表必须包含以下列：

| 列名 | 类型 | 说明 |
| ---- | ---- | ---- |
| `id` | BIGSERIAL / VARCHAR(32) | 主键，雪花算法 ID |
| `created_at` | TIMESTAMP | 创建时间，默认 CURRENT_TIMESTAMP |
| `updated_at` | TIMESTAMP | 更新时间，自动更新 |
| `deleted_at` | TIMESTAMP | 逻辑删除时间，NULL=未删除 |

#### 乐观锁

对于高并发更新场景（号源扣减、库存变化等），使用 `version` 字段实现乐观锁：

```sql
version INT NOT NULL DEFAULT 0,
-- 更新时: UPDATE ... SET ... version = version + 1 WHERE id = ? AND version = ?
```

## 十九、通用索引策略

### 19.1 索引设计原则

1. 每个表的主键自动建立唯一索引
2. 外键列建立普通索引
3. 高频查询条件的列建立复合索引
4. 唯一约束列自动建立唯一索引
5. 逻辑删除查询统一添加 `WHERE deleted_at IS NULL`

### 19.2 通用索引示例

```sql
-- 患者表
CREATE INDEX idx_patients_phone ON patients(phone);
CREATE INDEX idx_patients_id_card ON patients(id_card);

-- 挂号表
CREATE INDEX idx_registrations_patient ON registrations(patient_id);
CREATE INDEX idx_registrations_date ON registrations(register_date);
CREATE INDEX idx_registrations_status ON registrations(status);

-- 处方表
CREATE INDEX idx_prescriptions_patient ON prescriptions(patient_id);
CREATE INDEX idx_prescriptions_status ON prescriptions(status);
CREATE INDEX idx_prescriptions_encounter ON prescriptions(encounter_id);
```
